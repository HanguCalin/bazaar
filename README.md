# bazaar

A small e-commerce backend in C++20, designed and built from an empty
repository over 12 weeks as interview preparation. See [PLAN.md](PLAN.md) for
the plan, `docs/WEEKn.md` for each week's tasks and spec, and
`docs/WEEKn_EXPLANATIONS.md` for the background behind them.

Build instructions arrive with the build system in week 1.
